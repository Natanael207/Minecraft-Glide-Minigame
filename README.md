# Minecraft-Glide-Minigame

This is a data and resourcepack for the Glide-Minigame.

Download the Minecraft map here:
https://www.youtube.com/watch?v=WPHREGKF2a0

Move the data pack to the "datapacks" folder of your Minecraft world. 
You can find it at %appdata%\.minecraft\saves\[Minecraft world name]\datapacks.

Move the resource pack to the %appdata%\.minecraft\resourcepacks folder.

Then load the world.
